# 品牌表达

品牌人格在本技能中作为跨模式的表达约束。适用于品牌、机构、栏目和个人作者；风格需要延续时读取，没有品牌任务时无需制造人格设定。

## 依据顺序

以本次明确要求和已确认规范为先，再参考被认可的现行样稿。旧活动、临时节日文案和特殊场景只能作为局部参考，不自动代表长期风格。

材料冲突时检查日期、用途、认可状态和本次要求。两个方向都会影响成品且无法判断时询问，不把冲突样稿机械平均。

只给一两句样稿时，可以延续可观察的称呼、节奏和语气；不要据此宣称已建立完整品牌人格。无材料时可为本次任务提出暂定表达方向，不能补造历史、使命、客户群体或价值立场。

## 建立可执行的表达档案

仅在长期延续或多稿件任务需要时记录下表。引用样稿应保留来源位置，区分观察结果与暂定判断。

| 项目 | 应记录什么 | 不应怎样写 |
|---|---|---|
| 对读者的立场 | 尊重何种处境，提供什么帮助 | “懂所有年轻人的品牌” |
| 价值判断 | 有材料支持的持续选择 | 临时编造宏大使命 |
| 观察角度 | 常从哪种问题或细节切入 | 将单句修辞当成固定世界观 |
| 称呼与词语 | 人称、对象称谓、常用及禁用词 | 随意增加昵称、亲密称呼 |
| 句式与节奏 | 长短句比例、解释程度、口语程度 | 每句都复制同一结构 |
| 情绪与幽默 | 温度、直接程度、调侃边界 | 在所有场景维持同样强度 |
| 事实姿态 | 怎样说明条件、证据与限制 | 用语气掩盖依据不足 |
| 场景变化 | 广告、通知、说明、售后如何调整 | 把一种口吻铺到所有位置 |

档案应包含具体例证，例如“标题以动作开头，正文常直接说明可以获得什么”；“高级、有质感、年轻化”不足以指导稳定写作。

## 稳定什么，调整什么

通常稳定的是对读者的尊重、称谓、价值边界与基本语言气质。根据任务调整信息密度、句子长度、情绪强度和幽默程度。

同一品牌可以在海报上简短，在产品说明中细致，在服务故障通知中直接负责。语气一致不等于句式一致，也不等于每篇都重复口号。

用户指定新的本次风格时，以任务要求为准；若其与既定长期规范冲突，必要时简短指出差异，不能擅自回退或把本次方向写成永久规范。

## 写作方式

先完成任务与事实，再按档案调整表达。不要为“像品牌”删除条件、制造情绪或使用不准确称谓。

借鉴样稿时提取观察角度、细节选择、节奏与语气，再围绕本次对象重新写。不得通过替换少量词语搬用他人的识别性口号、比喻或段落结构。

用户要求特定作者或品牌风格时，遵守所在环境的风格与版权规则；可采用清楚、克制、简短、口语等通用特征，不承诺复制独特表达。

## 判断方法

- **一致性**：是否符合现行规范或本次明确方向？具体哪些词句相容或冲突？
- **可辨认性**：是否有持续出现的立场、观察和语言特征？缺少读者测试时不宣称“无人看署名也能认出”。
- **适应性**：换成说明、通知或售后任务，是否还能保持气质并把事项说清？
- **内容支持**：品牌所表达的立场，是否有本次事实或实际行动支持？

“这句话换一个品牌说也成立”可以提示进一步检查，但不能直接判定不合格。短按钮、服务通知与行业通用术语无需追求独占表达。

## 常见失败

“独特”变成故作姿态：回到读者和对象，用具体选择体现立场。

“一致”变成复读口号：保留气质，改变切入点和内容单位。

“有温度”变成过度亲密：使用被认可的称谓，尊重读者距离。

“专业”变成术语堆砌：保留必要术语，说明实际含义和条件。

“幽默”盖住严重问题：先说明影响、责任和处理方式，再决定是否允许轻松措辞。

品牌表达通过与任务模式相同的事实、可理解性及交付检查。风格不能豁免这些要求。
