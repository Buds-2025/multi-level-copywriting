# 选择表达

适用于购买、报名、采购、订阅、采纳建议、选择服务或参与行动。目标是帮助特定读者作出有根据的判断，不必每次与竞争对象对比。

## 找到真正影响选择的因素

从读者的任务、现有替代方案和关键疑虑出发。产品特点只有与读者的决策有关时才构成选择理由。

可考察：适用性、所需步骤、时间成本、总成本、兼容条件、学习难度、服务边界、风险、可靠性和体验。只选择材料能够支持且本次最有用的因素，不写无来源的用户心理画像。

问题应具体：“团队为什么愿意切换？”可能涉及迁移成本；“新人为什么愿意报名？”可能涉及先修要求与能带走的成果。不能用“品质卓越、值得信赖”统一回答所有疑虑。

## 从事实到选择理由

使用这条检查链：

**事实或能力 → 在特定条件下带来的结果 → 对这类读者的价值 → 支持判断的依据。**

这条链用于检查逻辑，无需按顺序写成四句话。

例如题设确认“提供可编辑示例文件”，可写“跟着示例修改，带走自己的练习文件”。不能直接写“零基础也能成为专家”，因为材料没有支持学习结果。

利益不能越过功能边界。减少一个环节，不等于完全免操作；提供提醒，不等于保证不会错过；支持某种格式，不等于兼容所有设备。

## 可选方法

- **适用性表达**：清楚说明适合谁、解决哪项任务，以及重要边界。
- **差异理由**：突出有证据且对当前读者重要的特点，不必罗列所有优势。
- **证据解释**：让读者知道数据、演示或案例具体证明什么。证据越强，表述也不能超出其范围。
- **疑虑回应**：回答真正影响决定的问题，例如上手条件、交付内容、费用构成或服务范围。
- **成本与条件透明**：说明材料确认的价格、时间投入、前提与可获得内容，不将未确认条件写成优惠。
- **明确行动**：任务需要转化时提供真实入口与下一步；入口未知时追问或完成不依赖入口的部分。

不是每项都必须出现。短广告可突出一个有力理由；采购材料可能需要多项依据和限制。

## 比较与差异

不同方案的比较必须同对象、同版本、同时间、同测量口径。自己的已知特点不自动证明竞争对象缺少该特点。

没有竞争材料时，可以强调自身适用性，不能写“同行都做不到”“唯一解决方案”等比较暗示。不得给替代方案制造虚假的痛点。

选择也可能是“不适合本次需求”。材料显示重要限制时说明适用边界，不能为成交删除会改变决定的事实。

## 常见失败与改法

| 问题 | 修改重点 |
|---|---|
| 特点清单很长，没有决策意义 | 找出读者真正需要的一两项，并解释价值 |
| 利益说得很大，没有依据 | 收窄到已确认能力能支持的结果 |
| 只有情绪，没有理由 | 增加实际交付、条件或可观察证据 |
| 与竞争对象比较但口径不明 | 补齐比较材料，或改写为自身事实 |
| 行动按钮与承诺不匹配 | 调整下一步，使读者知道实际会获得什么 |
| 用催促替代价值解释 | 明确参与理由；没有真实期限就不创造期限 |

## 验收

读者是否知道“这与我有什么关系”？是否能找到支持理由的事实？重要疑虑是否得到适当回应？是否知道适用条件与下一步？

质量判断依赖具体任务。文案有理由且可信，并不意味着一定带来转化增长；实际效果需通过相应场景的观察或测试确认。
