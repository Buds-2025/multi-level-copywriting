# 传播表达

适用于希望内容被引用、讨论、推荐或分享的任务。传播潜力是一种待验证的判断，不能承诺“必火”或将文案特征等同于传播结果。

## 找到分享动机

读者可能因为内容有用、能表达自己、与他人处境有关、有趣、提出新观察，或有助于共同参与而分享。选择与本任务及对象有关的动机，不要求必须制造冲突。

可用问题：读者会把内容发给谁？为什么发？分享这句话会表达什么？接收者是否看得懂？这些判断只能基于材料与情境，不能假定所有读者必然认同。

## 双重关联检查

检查两个维度：

1. **独立传播价值**：读者转述时，是否仍有用、有意思或能表达立场？
2. **对象关联**：内容被截图或摘引后，是否还能与品牌、活动、产品类别或明确议题联系？

“去掉Logo还有没有人愿意分享”只检查了第一项，不能单独作为好文案标准。传播表达可以依赖画面、标题或署名，但必须确认这些载体确实会一起出现；若用户要求可单独转发的文字，就把最低限度线索写进文字。

有些公共议题内容不需要每句提及品牌。这时关联可以由整篇内容和实际行动建立，不能硬塞品牌名，也不能在内容完全脱离任务时只靠署名补救。

## 可选方法

- **替读者说清一个经验**：从具体场景发现可识别的共同处境，不宣称代表所有人。
- **一个有依据的新观察**：解释熟悉事物中的被忽略之处，避免编造冷知识或数据。
- **一份值得保存的内容**：清单、方法、判断标准或简明解释；分享价值可以来自实用性。
- **一个清楚的立场**：与品牌材料或任务目标一致，能说明支持什么及原因。
- **一个适合参与的问题**：与对象或场景有关，让读者有真实经验可谈；不强行安排二选一对立。
- **适度幽默**：笑点来自情境和观察，避免以弱势群体、灾难或未经核实的人物为素材。

可引用表达通常需要明确对象、紧凑措辞和可理解的关系。不要把“短、押韵、反转”当作必备条件，更不能为制造反转歪曲事实。

## 传播单元与正文

长内容可以有一个适合摘引的句子，正文提供事实、方法或场景支持。标题承诺的价值必须在正文兑现，不能借夸张标题吸引后再给无关内容。

品牌名和行动入口是否出现，由传播目标和载体决定。用户只要讨论话题时不强加购买动作；用户要带动报名时，实际信息与入口必须真实、可用。

借用公共事件时检查时间、来源、对象关系与语境。无法核实就不用该事实切口。不能把他人的遭遇写成虚构的亲历宣传材料。

## 常见失败与改法

| 问题 | 修改重点 |
|---|---|
| 好听但没有分享理由 | 增加实际价值、具体经验或清楚立场 |
| 分享后与对象完全失联 | 调整切口或加入真实关联线索 |
| 为冲突夸大事实 | 回到可支持的观察和条件 |
| 只迎合群体情绪 | 补观点依据、实际方法或对象贡献 |
| 标题和正文不一致 | 收窄标题承诺，或补足正文内容 |
| 口号后面硬贴品牌名 | 让议题与对象的实际能力或行动产生联系 |

## 验收

分享动机是否具体？摘引后是否容易误解？对象关联是否充分？正文是否兑现？表达是否有事实边界？

没有实际测试时，只能判断写法是否具备合理分享条件。评价时说明可观察的表达特征，不声称已证明传播效果。
