# 任务识别与模式选择

用于复杂输入、需求冲突、读者分群、整组内容和多功能组合。简单任务直接使用SKILL.md中的判断即可。

## 从材料建立任务简报

下表供内部判断，用户要求策略说明时才输出。字段不必全部填满，不能把表格当作每次写作的门槛。

| 项目 | 需要识别的内容 | 会改变什么 |
|---|---|---|
| 交付物 | 单句、标题、海报、页面、长文、口播、消息、改稿或诊断 | 内容单位和输出形式 |
| 对象 | 实际产品、服务、活动、观点、行动或作者 | 可表达的事实与价值 |
| 读者 | 与任务有关的人群、既有认识、需求、疑虑 | 信息解释程度、理由与措辞 |
| 使用位置 | 展示渠道、版位、阅读时长、相邻内容、设备 | 篇幅、上下文与信息分工 |
| 目标 | 理解、判断、期待、参与、分享、识别等可观察反应 | 主任务和验收依据 |
| 证据 | 已确认事实、来源、案例、原稿、品牌样稿 | 可支持的表述范围 |
| 约束 | 字数、语言、结构、禁用词、不可改部分、承诺边界 | 硬性条件 |
| 权限 | 仅写稿、保存文件、发送或发布等已有授权 | 可执行的动作 |
| 停止条件 | 何种结果算完成，哪些疑点必须解决 | 是否需要继续修正 |

不要从年龄、性别、地域推导未经支持的心理特征。用与任务有关的处境描述读者，例如“第一次为小型团队采购会议服务，担心部署麻烦”，通常比泛化的“年轻用户”更有指导价值。

## 输入不足时怎样推进

按缺项的后果处理，不按字段是否空白处理。

- **可直接采用的编辑默认值**：没有口吻要求时自然清楚；没有版本数要求时交付一个最佳版本；没有格式要求时选择易用的文本结构。
- **可从材料推断但需克制的条件**：已有内容明显是购买页时，可围绕选择理由组织；不推断未提供的折扣、库存或支付方式。
- **需要追问的核心事实**：无法辨认对象；活动报名文案缺时间或入口且用户要求完整发布稿；产品主张依赖未提供的效果证据；原稿与最新明确材料出现实质冲突。
- **可删去的非关键缺项**：缺少销售数字时不用数字；缺少用户证言时不用证言；没提供品牌故事时不补写创始故事。
- **可先完成的独立部分**：活动规则待定时先完成已确定的介绍段，剩余报名信息明确列为缺口；不要把未确定内容嵌入成品假装完整。

追问应具体，例如“报名稿还缺活动日期和报名入口，请提供这两项。”避免一次索要十几项资料，或者在已有答案时再问。用户要求先出草稿时可交付明确标识的草稿，不能因“草稿”而编造事实。

## 从预期反应选择功能

1. 读者还不知道对象、规则或操作，而且这是当前任务的障碍：信息优先。
2. 读者知道大致对象，需要判断适不适合、值不值得或是否参与：选择优先。
3. 读者需要感受使用或参与的意义，抽象利益难以被体验：向往优先。
4. 任务明确希望引发引用、讨论、推荐或分享：传播优先。

这些条件可重叠，也可能不存在唯一主功能。用户明确要求平衡多功能时按其要求组合；不要为了方便分类强行归入单一模式。

“更有说服力”通常需要明确利益、依据和疑虑；“更有温度”通常需要更贴合处境；“更高级”含义不明确时，先从原稿问题判断是简洁、具体、克制还是品牌一致。能作出合理调整就直接改；不同解释会产生明显不同结果时再问。

## 渠道只提供约束

| 位置 | 常见但非固定的任务 | 需要特别处理 |
|---|---|---|
| 包装、说明、按钮、流程提示 | 信息、选择 | 操作能否完成，术语是否一致 |
| 详情页、采购介绍、招生报名页 | 选择＋信息 | 适用人群、证据、条件、行动入口 |
| 品牌海报、封面、展示广告 | 向往、信息、传播均可能 | 短句与画面共同表达，不能假设隐藏信息 |
| 社交平台、公众号、社区 | 四种功能均可能 | 标题兑现、讨论关联、内容实际价值 |
| 短视频、直播、口播 | 四种功能均可能 | 口头理解、停顿、展示事实、前后承接 |
| 邮件、通知、服务消息 | 信息、选择 | 时间、事项、责任和明确下一步 |
| 公益倡议、公共参与 | 信息、选择、传播 | 行动门槛、公共价值、尊重对象 |

不要给渠道设定永恒的“最佳字数”“爆款句式”或平台规则。用户指定限制优先；需要使用当前规则时核查原始来源。

## 如何组合

组合由阅读任务决定，无需规定固定比例。

- **一句话或一个按钮**：完成一个清晰动作，不堆多重利益。
- **海报主副标题**：主标题承担注意或价值表达，副标题补必要对象或条件；只有确实存在副标题时才能依赖它。
- **购买页**：读者可先判断适用性，再看依据、条件和操作；顺序由读者认识与页面目标决定。
- **长文或口播**：将不同功能分配给段落，避免开头情绪强烈，中间突然变成无关参数清单。
- **一组内容**：不同稿件可以分别解释、促成选择、呈现场景和引发分享，保持事实及品牌语气一致；不要复制同一口号到所有位置。

如果辅助表达挤掉主任务所需信息，应删减辅助表达。例如报名通知必须留住时间、地点或参与方式，不能为了氛围省掉。

## 冲突处理

先检查能否利用版位分工、简化句子或减少非必要目标同时满足要求。

- 指定品牌轻松语气，但内容涉及服务故障：保留友好措辞，清楚说明影响和处理方式，避免玩笑盖住事实。
- 要求极短，同时要求包含大量必要规则：优先保留完成任务的核心信息；若长度下确实放不下，指出具体冲突，提供可审阅的短版与补充信息位置建议，不谎称全部包含。
- 用户要传播文案，但没有品牌线索：可用与对象直接相关的讨论切口，不擅自创造品牌使命。
- 用户要求保留原句，但原句包含无法支持的承诺：明确指出该处事实问题；其他内容照常完成，不把风险句静默保留为成品。

完成条件由目标、事实与用户约束共同确定。得到一个适合任务的结果即可停止，不继续追求所谓更高层次。
