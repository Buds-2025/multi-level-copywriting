# 多层次文案写作

按用途选择信息、选择、向往、传播四种文案功能，并延续品牌表达。支持新写、改稿、诊断、多版本比较和跨渠道适配，不设高低等级。

将仓库目录放入技能目录，使用`$multi-level-copywriting`调用；也可直接指定[SKILL.md](SKILL.md)，附上材料、读者、用途和限制。

## 目录

```text
multi-level-copywriting/
├── README.md
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── aspiration.md
    ├── brand-voice.md
    ├── brief-routing.md
    ├── choice.md
    ├── claims-evidence.md
    ├── examples.md
    ├── information.md
    ├── quality-gates.md
    ├── revision-delivery.md
    └── sharing.md
```
